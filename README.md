## Project setup

```bash
$ yarn install
```

## Environment variables
```
Clone the .env.example file and rename it to .env
```


## Compile and run the project

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:dev
```
## Execute SEED

```
http://localhostL:3000/api/seed
```
